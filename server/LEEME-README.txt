VitaMon - PC monitor for the PS Vita
https://github.com/MrWhite2312-IS/VitaPCMonitor

ENGLISH
1. Keep this whole folder together (VitaMon.exe needs the _internal folder).
2. Double-click VitaMon.exe. It starts sending to your Vita right away.
3. The first time, allow it on "Private networks" when Windows asks.
To start it with Windows, tick "Open when Windows starts" in the window.

ESPAÑOL
1. Mantén toda esta carpeta junta (VitaMon.exe necesita la carpeta _internal).
2. Haz doble clic en VitaMon.exe. Empieza a enviar datos a la Vita enseguida.
3. La primera vez, permite el acceso en "Redes privadas" cuando Windows pregunte.
Para abrirlo con Windows, marca "Abrir al iniciar Windows" en la ventana.
